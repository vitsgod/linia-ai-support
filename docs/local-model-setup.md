## Источник модели и установка

Загрузка через `ollama pull` была отклонена: домен хранилища разрешался в непубличный адрес 198.18.20.13 из-за Fake-IP DNS. Пользователь не мог изменить VPN. Поэтому использован документированный импорт локального GGUF из официального репозитория Qwen; настройки и защиту Ollama не ослабляли, VPN не меняли.

Источник: Qwen/Qwen3-4B-GGUF на Hugging Face, ревизия `bc640142c66e1fdd12af0bd68f40445458f3869b`, файл `Qwen3-4B-Q4_K_M.gguf`, 2 497 280 256 байт. SHA256 сверена с официальными метаданными:

```text
7485fe6f11af29433bc51cab58009521f205840f5b4ae3a32fa7f92e8534fdf5
```

Исходный GGUF сохранён в `.local/qwen3-4b-q4km.gguf`, импортированные веса — в обычном пользовательском хранилище Ollama. Оба не входят в Git. Повторить импорт из папки проекта:

```powershell
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" create qwen3:4b --file models\Modelfile
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" list
```

Затем из папки проекта:

```powershell
.\.venv\Scripts\python.exe scripts\check_local_model.py
& "$env:LOCALAPPDATA\Programs\Ollama\ollama.exe" ps
```

Проверочный скрипт отправляет вымышленный пример проблемы с Wi-Fi через POST /api/chat, ожидает завершённый непустой ответ и сохраняет результат в .local/model-check.json. Первый замер сохранён отдельно в .local/model-check-cold.json. Для запуска после выхода из Ollama достаточно открыть установленное приложение из меню Windows.

## Понятия

Ollama — программа для запуска моделей и локальный HTTP-сервер. Qwen3 4B — сама модель, то есть скачиваемые веса нейросети. Установка программы и скачивание модели — два разных шага. API-ключ для локальной модели не нужен.

Промпт — инструкции и вопрос, которые отправляются модели. В messages роль system задаёт поведение помощника, user содержит описание проблемы. stream=false позволяет получить ответ целиком одним JSON. think=false отключает отдельный режим рассуждений для этой проверки. FastAPI теперь вызывает модель через POST /api/diagnostics; React вызывает её через кнопку диагностики, а создание заявки остаётся отдельным действием. Подробности учебного API — в README.
