# Карточка проекта

**Линия — локальный AI-помощник техподдержки**

Учебный fullstack-проект, созданный с помощью AI: React/TypeScript, FastAPI, PostgreSQL/pgvector и локальные модели через Ollama. Сервис сохраняет заявки, ищет инструкции по смыслу, показывает ответы с источниками и проверяет учебные аварии через ограниченный инструмент. Помощник предлагает редактируемый черновик; создание заявки требует отдельного действия пользователя. История операций хранится в БД. Запуск подготовлен через Docker Compose, проверки — через тестовый контейнер и workflow GitHub Actions.

## Что разбирать на собеседовании

- Путь запроса от React через API до SQL и обратно; валидация и коды ошибок.
- Различие генеративной и embedding-моделей, индексация фрагментов и поиск pgvector.
- Почему ближайший вектор не обязательно релевантен; зачем нужны порог, источники и проверка качества.
- Разделение предложения модели и выполнения Python-функции: разрешённое имя инструмента, проверка района и лимит вызовов.
- Различие черновика, сохранённой заявки и записи журнала.
- Различие образа, контейнера и volume; изолированная тестовая БД.

Это учебный опыт AI-assisted разработки. Коммерческий опыт, работа с реальными абонентами, облачное развёртывание и успешный облачный CI не заявляются. Описание личного вклада стоит дополнять только тем, что автор может самостоятельно объяснить и показать в коде.

README и сценарий демонстрации готовы для локального показа. Публичный репозиторий: https://github.com/vitsgod/linia-ai-support. Публичного развёрнутого сервиса пока нет.
